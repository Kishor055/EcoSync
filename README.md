# 📖 Overview

**EcoSync AI** is a next-generation Sustainability Operating System designed to monitor, analyze, and optimize energy, water, carbon emissions, and smart infrastructure in real time.

Built using **Next.js 15**, **Firebase**, **Google Genkit**, and **Gemini AI**, EcoSync provides organizations with a unified command center to reduce operational costs, improve efficiency, and achieve sustainability goals.

The platform combines real-time IoT monitoring, AI-powered recommendations, predictive maintenance, and digital twin simulations into a single enterprise-grade dashboard.

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/Kishor055/EcoSync.git
```

```bash
cd EcoSync
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment

Create a `.env.local`

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY

NEXT_PUBLIC_FIREBASE_API_KEY=

NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=

NEXT_PUBLIC_FIREBASE_PROJECT_ID=

NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=

NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=

NEXT_PUBLIC_FIREBASE_APP_ID=
```

---

## Firebase Setup

Enable:

- Authentication
- Firestore Database
- Storage

Deploy Security Rules

```bash
firebase deploy --only firestore:rules
```

---

## Start Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

# 🚀 Production Build

npm run build

Run

npm start
